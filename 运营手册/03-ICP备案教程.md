## 第 1 步：买国内域名（如已有跳过）

1. 在阿里云（https://wanwang.aliyun.com）或腾讯云搜索心仪域名
2. 推荐：`ahbowei.cn` / `ahbowei.com.cn` / `bowei-gy.com`（"gy"=工业）
3. .cn 域名约 30-40 元/年，.com 约 60-80 元/年
4. 购买时必须实名认证（个人或公司执照均可，建议用公司）

## 第 2 步：买国内服务器

| 方案 | 配置 | 价格 | 适合 |
|---|---|---|---|
| 轻量应用服务器（推荐） | 2核2G + 60G SSD | 约 99-200 元/年（新用户常有活动价） | 纯静态网站绰绰有余 |
| 云服务器 ECS | 2核2G | 约 300-500 元/年 | 以后要加功能 |

- 阿里云：https://www.aliyun.com/product/swas（轻量服务器）
- 腾讯云：https://cloud.tencent.com/product/lighthouse
- **地域选华东（上海/杭州/南京）**，离合肥客户近，速度快
- 系统选 Ubuntu 22.04 或 Windows Server（不熟 Linux 就选 Windows，好操作但贵一点）

## 第 3 步：ICP 备案（核心步骤，免费，1-2 周）

1. 在买服务器的同一家云厂商控制台找「备案」入口：
   - 阿里云：控制台 → ICP 备案（beian.aliyun.com）
   - 腾讯云：控制台 → 备案（beian.cloud.tencent.com）
2. 按提示填写：
   | 项目 | 填什么 |
   |---|---|
   | 主体类型 | 企业（用营业执照） |
   | 主体信息 | 公司全称、统一社会信用代码、法人信息 |
   | 网站负责人 | 建议填法人本人（需人脸核验+手机验证码） |
   | 网站名称 | 「安徽柏威工业技术有限公司官网」（**不要带"液压夹具"等产品词**，会驳回） |
   | 服务内容 | 企业门户网站 |
   | 备注 | 公司官网，展示公司介绍与产品信息 |
3. 提交后：
   - 云厂商初审（1-2 天）
   - 管局审核（约 7-15 天，安徽省管局）
   - 期间**手机保持畅通**，管局可能电话核验（问：网站做什么的？答：公司官网，介绍公司和产品即可）
4. 通过后拿到 **ICP 备案号**（如：皖ICP备XXXXXXXX号），挂到网站页脚

## 常见问题

**Q：不备案行不行？**
海外线（谷歌/ChatGPT）不受影响，但百度收录、国内访问速度、豆包/文心的国内引用都会很差。国内线必须备案。

**Q：两个网站会不会冲突？**
不会。anhuibowei.com 服务海外，国内域名服务国内，内容一样，各自提交各自的搜索引擎。

**Q：备案麻烦吗？**
主体资质齐全的话全程在线，约 1-2 周，期间不需要跑腿。最难的一步是人脸核验，需要法人配合 5 分钟。
