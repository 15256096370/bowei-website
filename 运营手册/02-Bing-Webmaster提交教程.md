# 02 · Bing Webmaster 提交教程（喂给 ChatGPT / DeepSeek 的入口）

> Bing 是 ChatGPT 联网搜索和 DeepSeek 联网搜索的主要数据源。
> 这一步性价比极高，必须做。耗时：15 分钟。免费。

---

## 第 1 步：注册微软账号（如已有 Outlook/Hotmail 跳过）

1. 打开 https://signup.live.com 注册

## 第 2 步：添加网站（最快方式：从谷歌一键导入）

1. 打开 https://www.bing.com/webmasters
2. 登录 → 点「添加网站」
3. 选择「**从 Google Search Console 导入**」（需已完成手册 01）
4. 授权谷歌账号 → 选择 `anhuibowei.com` → 导入成功，验证、sitemap 全部自动带过来

> 如果不想用谷歌导入，也可手动：输入 `anhuibowei.com` → 按提示添加 DNS CNAME/TXT 验证 → 提交 `sitemap.xml`。

## 第 3 步：提交重点 URL（加速收录）

左侧「URL 提交」→ 逐个粘贴以下地址 → 提交：

```
https://anhuibowei.com/
https://anhuibowei.com/en/
https://anhuibowei.com/en/hydraulic-fixture.html
https://anhuibowei.com/en/zero-point.html
https://anhuibowei.com/en/ball-lock.html
https://anhuibowei.com/en/exchange-table.html
https://anhuibowei.com/en/automation.html
https://anhuibowei.com/en/products.html
https://anhuibowei.com/en/cases.html
https://anhuibowei.com/en/contact.html
```

## 第 4 步：验证 AI 引用（隔 2 周自查一次）

1. 打开 ChatGPT（chatgpt.com）开启「搜索」模式，问：
   "Anhui Bowei Industrial Technology hydraulic fixture manufacturer"
2. 打开 Perplexity（perplexity.ai），问同样的问题
3. 如果提到你：✅ 成功；没提到：继续按「营销文案/04-LinkedIn文案.md」铺内容

## 为什么做 Bing 不做别的？

| 引擎 | 数据来源 | 对你的意义 |
|---|---|---|
| ChatGPT 联网 | 主要是 Bing | 提交 Bing = 喂给 ChatGPT |
| DeepSeek 联网 | Bing 类 + 中文源 | 同上 |
| Google AI | Google 索引 | 手册 01 已覆盖 |
| 豆包 | 字节系 + 百度系 | 靠爱采购/头条/知乎内容（手册 05） |
